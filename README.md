# 🎓 Learning Point Coaching Center - Official Website

Welcome to the official website project for **Learning Point Coaching Center** (Classes 1 to 10). 

This website provides information about batches and subjects, answers frequently asked questions, and allows parents and students to submit admission inquiries directly via WhatsApp and store admission data into Google Sheets / Excel.

---

## ✨ Key Features

1. **📱 Responsive Design**: Works seamlessly on mobile phones, tablets, and desktop computers with a clean hamburger navigation menu.
2. **📚 Classes & Batches**:
   - **Primary Wing (Class 1 - 5)**: Foundation building & reading skills.
   - **Middle Wing (Class 6 - 8)**: Conceptual understanding & problem-solving.
   - **Secondary Wing (Class 9 - 10)**: Board exam preparation & advanced learning.
3. **🎯 Main Subjects Highlight**: Mathematics, Science, English, Social Science, and Hindi.
4. **❓ Interactive FAQ**: Collapsible questions and answers built using pure HTML `<details>` and `<summary>` tags.
5. **💬 Instant WhatsApp Inquiries**: When parents submit the inquiry form, it automatically formats their details and opens WhatsApp to chat directly with the coaching center.
6. **💾 Direct Admission Data Storage**:
   - Stores student admission inquiries directly into **Google Sheets** in real time.
   - Keeps records safe online so you can view all submissions anytime from your phone or computer.

## 🚀 How to Run the Website

### Method 1: Using VS Code Live Server (Recommended)
1. Open this project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by *Ritwick Dey*) from the Extensions marketplace.
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. The website will automatically open in your default web browser.

### Method 2: Direct Browser Opening
1. Open Windows File Explorer.
2. Navigate to your project folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

## 📝 How the Admission Form Works

1. A parent or student enters:
   - **Student Name**
   - **Class** (Class 1–5, 6–8, or 9–10)
   - **10-Digit Mobile Number**
2. When they click **Submit Admission Inquiry**:
   - The data is sent and saved to your **Google Sheet**.
   - A WhatsApp chat automatically opens with a pre-filled admission inquiry message directed to `+91 9122844639`.
